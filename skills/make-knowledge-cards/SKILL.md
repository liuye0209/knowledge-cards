# Make Knowledge Cards

## 概述

把文章转换为 5~8 张知识卡片。三条铁律：

1. **卡片数量由原文决定** —— 5~8 是典型范围，不是必须凑满的配额。
2. **一张卡片只讲一个知识点** —— 多个知识点不得挤进一张卡，同一知识点也不得拆成多张。
3. **只写原文存在的信息** —— 不编造、不补充背景知识、不添加原文没有的例子。

## 输入

接受两种输入：

- 用户直接粘贴的文章全文
- 本地 Markdown（`.md`）或纯文本（`.txt`）文件路径 —— 先完整读取文件再处理

遇到以下输入，直接说明"暂不支持"并停止，不要变通处理：网页 URL（不抓取网页）、PDF、Anki 导出、图形界面。

## 工作流程

### 1. 提取知识点

通读原文，列出所有独立的知识点（事实、方法、机制、结论）：

- 只保留支撑主旨、值得读者记住的内容；删除寒暄、过渡、重复表述
- 同一知识点在原文出现多次 → 合并为一个知识点

### 2. 确定卡片数量

按合格知识点的数量 N 决定输出：

- N ≥ 8 → 选最重要的 8 个知识点，各出一张卡
- 5 ≤ N ≤ 8 → 每个知识点各出一张卡
- N < 5 → 全部输出，并在末尾附一行：`> 原文信息有限，仅生成 N 张卡片。`

凑数禁令：不得为达到 5 张而拆分知识点、换个说法复述已出的卡、或编造"背景/总结/元认知"卡片。

### 3. 填写卡片

按下方模板逐卡填写。`简明解释` 和 `例子/自测` 中的每一个事实、数字、例子都必须能在原文找到依据：只允许换说法，不允许引入新信息。原文没有合适例子时，改为出一道自测问题，其答案必须能从原文直接推出。

### 4. 自查后输出

对照"输出前自查"逐条核对，发现问题先修改再输出。

## 卡片模板

```markdown
### 卡片 1：<知识点名称作为标题>

**核心知识**：<1~2 句话陈述这个知识点>

**简明解释**：<用原文的信息进一步解释，可换说法，不可引入新信息>

**例子/自测**：<原文中的例子，或一道答案可从原文推出的问题>
```

输出语言：跟随用户提出该请求时所使用的语言；若请求没有文字描述（例如只给出文件路径），则使用原文语言。

## 输出前自查

- [ ] 每张卡片只讲一个知识点，没有把多个点挤进一张卡
- [ ] 任意两张卡片没有讲同一个知识点
- [ ] 每个事实、数字、例子、自测问题的前提与答案都能在原文找到出处，且不与原文矛盾
- [ ] 卡片数在 5~8 之间；不足 5 张时已附"原文信息有限"说明
- [ ] 输出只有卡片本身，没有附录、速记表、总结等额外板块

## 暂不支持

网页抓取、PDF、Anki 导出、图形界面。用户提出这些需求时直接说明，不要尝试变通方案。
